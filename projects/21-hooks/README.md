# React hooks

To run the project in development mode:

```
pnpm dev
```

To test the exercises, use the next paths:

- localhost:3000: ~useState~ example
- localhost:3000/mouse-over.html: ~useRef~ example
- localhost:3000/scroll.html: ~useEffect~ example

Project tech stack

- React 19 (loaded via import maps from esm.sh, no build step)
- React DOM
- pnpm (package manager)
- Zero-dependency Node.js static server (`server.js`)
